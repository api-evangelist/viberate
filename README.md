Viberate provides music analytics and data services, offering insights across platforms such as Spotify, TikTok, Apple Music, YouTube, and radio. Their platform delivers artist, song, playlist, audience, and festival analytics, along with industry trends and market intelligence, enabling A&R teams, event organizers, and artists to make data‑driven decisions.

**Areas:** Music · Analytics · Data · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Viberate: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
